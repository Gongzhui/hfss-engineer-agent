# 设计目标

这是一副带阻超宽带单极子。三个目标都要满足。某个频点 \(S_{11}\) 再深没有加分。

倒 U 形槽就是用来产生阻带的谐振器。微带线宽度需要自己计算一个合适的值。

**求解时间合计不得超过 3 小时。** 只计 HFSS 真正在算的时间：`parametric_start` 或 `analyze_start` 起到 `analyze_status` 返回 `done`。看模型、写日志、导出报告不算。每轮在日志写下 `solve_time`（用 job 的 `started_at` / `finished_at`，或自己记下起止），并自己加总到 `solve_total`。累计已满、或再开一轮会超过 3 小时，必须交卷：钉住当时最好的一组、导出单迹 `s11.csv`、写下 `stopped`、停止。不要再开新的 Parametric。正在扫的一轮可以等它结束，这一轮仍计入。未三项达标、且预估还能再开一轮：必须继续。互斥、平台期、「耦合问完」都不是交卷理由。

1. **阻带位置**：在 **6.6 GHz** 做出一段清晰阻带。以阻带内 \(S_{11}\) 最高点的频率为准，必须是 **6.6 GHz**（扫频步长 0.1 GHz，不要落到旁边的点上）。**6.6 GHz 这一点**必须抬到 **−7 dB 以上**（刚过 −10 dB 的浅缺口不算）。通带边界仍按 −10 dB 来划。
2. **阻带宽度**：不超过 **0.5 GHz**。在 0.1 GHz 栅格上，先标出所有 \(S_{11}\le -10\,\mathrm{dB}\) 的通带。缺口宽度 = 下侧通带的**最后一个**栅格点到上侧通带的**第一个**栅格点（这两个点本身仍 ≤ −10 dB）。不要用缺口内部 \(S_{11}>-10\) 的首尾两点相减，也不要按「高于 −10 的点数 × 0.1 GHz」来算——那会少掉两侧各 0.1 GHz。例如 6.3 GHz 仍 ≤ −10、6.4–6.9 GHz 高于 −10、7.0 GHz 又 ≤ −10，宽度是 \(7.0-6.3=0.7\,\mathrm{GHz}\)，不是 \(6.9-6.4=0.5\,\mathrm{GHz}\)。太宽会把超宽带通带挖空（开场那种 5–7 GHz 大塌陷不算）。
3. **相对带宽** ≥ **130%**。定义为阻带两侧通带外沿 \(f_L\)、\(f_H\) 的
   \[
   2(f_H - f_L)/(f_H + f_L).
   \]

看 Results 里整条 Modal \(S_{11}\)。通带中间别的频率上抬一下、或者把匹配失败当成阻带，都不算。调参手续见 AGENTS.md：联合扫参，不要单点跳变。
